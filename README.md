# Jendrik Illner - Rendering Programmer Portfolio

## Overview

This is the personal portfolio website of Jendrik Illner, a 3D and rendering programmer currently working at Santa Monica Studio. The website highlights Jendrik's experience in game development, including his work on projects such as God of War, Frostbite, Dead Space, and Far Cry 6.

## Features

- Home Page: Introduction to Jendrik Illner.
- Projects Section: Showcases key projects Jendrik has worked on.
- About Section: Provides details about Jendrik's professional background, education, and interests.
- Newsletter Section: Features Jendrik's Graphics Programming Weekly newsletter.
- Books Section: Lists recommended books for developers.
- Contact Section: Allows visitors to reach out to Jendrik.

## Technologies Used

- HTML5: Structure and content.
- CSS (Bootstrap 5.3.3): Styling and responsive design.
- JavaScript: Interactive elements.
- Google Fonts: Custom typography.
- Font Awesome: Icons for UI enhancements.

## Installation and Setup

1. Clone the repository:
   git clone https://github.com/ConstanzaMora/JendrikPortfolio.git
2. Navigate to the project directory: cd jendrik-portfolio
3. Open index.html in a web browser.
